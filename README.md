# 🚭 QuitSmoke Bot

Telegram-бот, который помогает бросить курить, используя научно обоснованные методики когнитивно-поведенческой терапии, геймификацию и трекинг прогресса.

## Возможности

### 📊 Трекинг прогресса
- Дни без сигарет
- Количество невыкуренных сигарет
- Сэкономленные деньги
- Возвращённые минуты жизни (+11 мин. за каждую невыкуренную сигарету)

### 🆘 SOS-кнопка (борьба с тягой)
7 научно обоснованных техник:
- **Дыхание 4-7-8** — активация парасимпатической нервной системы
- **Заземление 5-4-3-2-1** — переключение внимания от тяги
- **Правило 10 минут** — отложенное решение
- **Физическая активность** — замена никотиновой «награды» эндорфинами
- **Холодная вода** — дайверский рефлекс для снижения пульса
- **Визуализация** — создание позитивного образа будущего
- **Сёрфинг по волне** — осознанное наблюдение за тягой

### 🏥 Шкала восстановления здоровья
Реальная медицинская шкала (по данным ВОЗ и ACS): от 20 минут до 15 лет — что происходит с вашим организмом после отказа от курения.

### 🏆 Система достижений
18 достижений по категориям:
- Временные (1 час — 1 год)
- Финансовые (1 000₽ — 10 000₽)
- За борьбу с тягой (5 — 100 побеждённых приступов)
- За регулярные чекины

### 🙏 Мотивация
- Персональная причина бросить курить
- Случайные мотивационные цитаты
- Ежедневные утренние и вечерние напоминания

### 📋 Ежедневные чекины
- Утренний опрос (9:00 по локальному времени)
- Вечерняя мотивация (20:00)
- Трекинг настроения

### 🔄 Работа со срывами
- Бот не наказывает за срывы
- Поддерживающие сообщения
- Автоматический сброс таймера
- Статистика: «средний курильщик бросает 7-10 раз»
- Анализ триггеров с персональными советами

## Технологии

- **Python 3.12+**
- **aiogram 3** — асинхронный Telegram Bot API
- **SQLite** (aiosqlite) — хранение данных
- **APScheduler** — планировщик ежедневных задач
- **Docker** — контейнеризация

## Быстрый старт

### 1. Получите токен бота

Откройте [@BotFather](https://t.me/BotFather) в Telegram и создайте нового бота командой `/newbot`.

### 2. Настройте окружение

```bash
cp .env.example .env
# Отредактируйте .env и вставьте токен
```

### 3. Запустите через Docker

```bash
docker compose up -d
```

### Или локально

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

## Используемые методики

| Методика | Источник | Где в боте |
|----------|----------|------------|
| Когнитивно-поведенческая терапия (CBT) | NHS, APA | SOS-техники, анализ триггеров |
| Mindfulness (осознанность) | MBSR | «Сёрфинг по волне», заземление |
| Дыхание 4-7-8 | Dr. Andrew Weil | SOS-техника |
| Поведенческая замена | APA | Физическая активность, холодная вода |
| Геймификация | Self-Determination Theory | Достижения, трекинг |
| Таймлайн здоровья | WHO, ACS | Шкала здоровья |
| Мотивационное интервью | Miller & Rollnick | Персональная мотивация |
| Harm reduction | NICE guidelines | Поддержка при срывах |
