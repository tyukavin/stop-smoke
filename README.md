# 🔓 QuitSmoke Bot v2 — «Лёгкий способ»

Telegram-бот + REST API для освобождения от никотиновой зависимости. Поддерживает **сигареты, IQOS, вейпы и мини-вейпы**. Основан на методике Аллена Карра с элементами CBT и mindfulness.

## Возможности

### 🤖 Telegram-бот
- **Онбординг** для 4 типов устройств (сигареты, IQOS, вейп, мини-вейп) с разными расчётами
- **🔓 Моя свобода** — точные расчёты дней, денег, вредных веществ, возвращённой жизни
- **🆘 SOS** — 6 типов помощи: рациональная, переключение, поздравление, CBT, mindfulness, случайная (26+ сообщений)
- **🎭 Убийца мифов** — 15 мифов по 15 категориям (включая IQOS/вейп)
- **🏥 Здоровье** — 15 медицинских вех (ВОЗ/ACS)
- **🏆 Достижения** — 18 шт. с автоматическим разблокированием
- **💡 Мотивация** — 60+ уникальных цитат (Карр + CBT + здоровье + финансы)
- **📚 Материалы** — ссылки на книги, видео, приложения, сообщества
- **⚙️ Настройки** — редактирование профиля
- **Ежедневные чекины** — утренние аффирмации (9:00) и вечерняя мотивация (20:00)
- **Антиповтор** — система отслеживания доставленного контента, каждое сообщение уникально

### 🔐 Админ-панель (в боте)
Команда `/admin` для администраторов:
- 📊 Статистика пользователей и контента
- ➕ Добавление мотиваций, мифов, SOS-сообщений, CBT/mindfulness техник
- 📝 Просмотр и удаление контента
- ➕ Добавление материалов (ссылки)
- 📚 Управление материалами

### 🌐 REST API
`http://localhost:3000/api/`

| Endpoint | Auth | Описание |
|----------|------|----------|
| `GET /api/health` | — | Статус сервера |
| `GET /api/materials` | — | Публичные материалы |
| `POST /api/auth/token` | — | Получить JWT по telegram_id |
| `POST /api/auth/login` | — | Вход для админов |
| `GET /api/users/me` | JWT | Профиль пользователя |
| `GET /api/users/stats` | Admin | Статистика |
| `GET /api/users` | Admin | Все пользователи |
| `GET /api/progress` | JWT | Прогресс пользователя |
| `GET /api/progress/cravings` | JWT | Статистика тяги |
| `GET /api/progress/achievements` | JWT | Достижения |
| `GET /api/content` | Admin | Весь контент |
| `POST /api/content` | Admin | Добавить контент |
| `PUT /api/content/:id` | Admin | Обновить контент |
| `DELETE /api/content/:id` | Admin | Удалить контент |
| `POST /api/materials` | Admin | Добавить материал |
| `PUT /api/materials/:id` | Admin | Обновить материал |
| `DELETE /api/materials/:id` | Admin | Удалить материал |

## Технологии

- **TypeScript** + **Node.js 22**
- **grammY** — Telegram Bot API
- **Fastify** — REST API (с JWT аутентификацией)
- **better-sqlite3** — база данных
- **node-cron** — планировщик
- **Vitest** — тесты
- **Docker** — контейнеризация

## Быстрый старт

### 1. Получи токен у @BotFather

### 2. Настрой окружение
```bash
cp .env.example .env
# Отредактируй .env: BOT_TOKEN, ADMIN_IDS
```

### 3. Запусти через Docker
```bash
docker compose up -d
```

### Или локально
```bash
npm install
npm run bot
```

### Тесты
```bash
npm test
```
